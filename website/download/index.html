模拟与复盘

在模拟页选择 1,000、10,000 或自定义虚拟 USDT 本金，确认所选模型和滚动 24h 调用预算。公开研究形成条件后，由本地规则核对风险和后续可见盘口；不会真实下单。旧周期、订单与费用保留，新周期不清空历史。

定期冻结汇总；候选策略在等本金的独立虚拟账户中接受后续行情对照。至少七天、三十笔成对结算、完整费用且无观察缺口，净值与采样回撤达标才影响未来决策。门槛不是统计显著性或盈利保证。

支持范围

新入口聚焦 Binance。私有持仓核对 USDT 线性合约；公开事件研究仅覆盖在交易的 USDT 永续。不是整个加密市场，不含基本面、解锁或已核实项目身份映射。历史其他交易所适配器保留在源码中，不属于本轮工作台验收范围。

安装与首次使用

Apple Silicon 需要 macOS 13.0 或更新版本；Intel 需要 macOS 13.0 或更新版本。在“关于本机”核对芯片，打开对应 DMG，将 PositionScope.app 拖到“应用程序”。

公共参考行情无需交易所 Key。进入工作台 → 设置 → Binance 连接，保存 Binance 只读凭证；关闭交易和提现权限。AI 默认关闭，在设置中保存所选提供商、Key 与明确模型 ID 后，可主动查证。

独立应用身份不兼容或迁移旧预览版配置。Key 等配置通过 macOS 系统密钥加密；公共研究账本另存为 0600 权限 JSON。系统密钥不可用时不回退明文。
