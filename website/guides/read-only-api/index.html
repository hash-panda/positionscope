如何配置只读交易所连接

PositionScope 通过现有适配器读取 Binance、Bybit、OKX 和 Hyperliquid。请以交易所当前官方 API 页面为准创建凭证，产品不会替你验证所有权限开关。

连接前先核对权限

仅启用读取账户和持仓所需的权限，关闭交易和提现。按交易所支持配置 IP 限制；动态家庭 IP 是否适用，需要自行核对。不要把 API Secret、Passphrase、助记词或私钥贴到 GitHub Issue、社群或 AI 对话。

各交易所需要什么

  • Binance、Bybit：API Key 与 Secret。
  • OKX：API Key、Secret 与 Passphrase。
  • Hyperliquid：公开钱包地址，无需私钥。当前暂仅支持标准账户（disabled）的默认永续 DEX 和现货；统一、组合保证金、default及未知模式不生成汇总。应用不更改账户模式，请勿仅为试用而改变账户配置。USDC按1:1 USDT等值估算；其他DEX、质押与借贷未计入。

保存与连接是两件事

“凭证已保存”只表示本地写入成功；“已连接”需要成功取得账户数据。网络失败时保留上次数据并显示异常，不能把旧快照当实时行情。

数据在哪里

配置位于本机加密文件，密钥由 macOS 系统钥匙串管理。密钥不可用时不保存，原加密文件读取失败时保留并提示恢复；不导入此前预览版配置。请仅使用测试或低风险只读账户，并限制本机账户访问。AI 分析按需发送逐仓风险事实及平台权益到你选择的模型提供商，这些事实仍属于敏感财务信息。
