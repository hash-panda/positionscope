配置 Binance 只读连接

研究工作台的公开行情不需要交易所凭证。只有查看自己的账户和持仓时，才需在设置 → Binance 连接保存 Binance API Key 与 Secret。

先核对权限

按 Binance 当前官方说明，仅开启读取账户/持仓所需权限，关闭交易与提现。按自身网络情况设置 IP 限制；产品不会替你证明 Key 的全部权限。不要把 Secret、模型 Key、助记词或私钥贴到 Issue、社群或 AI 对话。

数据范围

当前持仓分析支持已校验的 USDT 线性合约；公共事件限 Binance 在交易的 USDT 永续。账户模式、结算资产、字段和时间不满足要求时保持不可用，不把缺数据补零。其他交易所是以后扩展范围；旧适配器源码存在不等于新版入口已验收。

保存不等于连接成功

保存完成只证明本地加密写入成功。连接成功需要完整读到支持的账户数据；失败时显示未知或明确标注上次快照。连续错误暂停后，可主动重连，不能把旧快照当作实时值。

公开 AI 与持仓 AI

在模型设置中保存明确提供商、Key 与型号，并核对接口兼容和价格。研究事件的“AI 查证”只发送已校验的公共市场证据，最多两次请求。独立的持仓分析会发送逐仓风险事实、账户权益等敏感财务信息；持仓分析需要用户主动操作。模拟周期在明确确认预算后可自动调用公开研究与虚拟汇总复盘；不发送真实持仓。模型费用由提供商收取，虚拟本金不抵扣真实账单。

本地保存

配置使用异步 safeStorage 系统加密，密钥由 macOS 钥匙串管理；不可用时保留原文件，不回退明文。独立应用身份不导入旧预览版配置。公共研究与模拟事件账本均为0600权限 JSON，原子替换但不加密，可能体现关注、策略与试验偏好；不要将它们公开。模拟重启后暂停自动调用，需主动恢复；没有旧预览版迁移。
