GOOD TO KNOW

开始之前

现在可以直接下载吗？

可以下载已签名、公证的 v0.2.0-beta.5。提供 Apple Silicon 与 Intel 的 DMG 和 ZIP；真实账户与原生交互仍需试用验证。

不开启 AI，可以使用吗？

可以。持仓和账户监控独立于 AI。只有点击分析且已配置所选提供商时，才会发起模型请求；模型调用费用按提供商规则另计。

这是 Binance 官方产品吗？

不是。PositionScope 是独立持仓监控项目，交易所名称用于标识数据来源，无官方关联或背书。

产品接下来如何改进？

按数据准确性、风险解释依据、小窗口体验、隐私与发布可靠性持续评审。进展通过 GitHub Issue 和 PR 留痕；只发布通过相应验证的改动。
