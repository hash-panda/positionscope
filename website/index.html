GOOD TO KNOW

开始之前

现在可以直接下载吗？

可以下载已签名、公证的 v0.2.3。提供 Apple Silicon 与 Intel 的 DMG 和 ZIP；真实账户与原生交互仍需试用验证。

不开启 AI，可以使用吗？

可以。公共行情、事件筛选、持仓与提醒独立于 AI。只有点击查证并配置可用模型时才发起请求；模型用量与费用按提供商记录核对。

有检查更新和红绿偏好吗？

设置 → 关于可主动检查官方稳定版，由你打开发布页下载安装。默认绿涨红跌，可切换红涨绿跌；隐藏金额时原生菜单立即遮罩并取消盈亏颜色。

提醒在退出后还能触发吗？

当前是应用内提醒：程序运行且联网时每 60 秒检查，首次样本建立基线，跨越阈值后提醒一次。退出或休眠期间不补触发，也不执行交易。

这是 Binance 官方产品吗？

不是。PositionScope 是独立持仓与研究项目，交易所名称用于标识数据来源，无官方关联或背书。

产品接下来如何改进？

按数据准确性、风险解释依据、小窗口体验、隐私与发布可靠性持续评审。进展通过 GitHub Issue 和 PR 留痕；只发布通过相应验证的改动。
