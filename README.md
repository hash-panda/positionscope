# PositionScope · 仓位镜

<img src="assets/brand/app-icon-128.png" width="64" height="64" alt="PositionScope 取景框与仓位刻度标识">

面向 Binance 的 macOS 只读持仓、AI 研究与本地模拟实验室。菜单栏看价格与盈亏，独立窗口查依据，用虚拟本金检验判断并保留各周期历史。

官网：https://positionscope.funagent.app/ 。下载、签名和验证状态以实际 [Releases](https://github.com/hash-panda/positionscope/releases) 为准。

## 0.2.7 功能范围

- **两种窗口**：480×600 速览展示 Binance 持仓、盈亏和 BTC/ETH 等自选公开行情；1180×760 可调整研究工作台提供研究、模拟、持仓、复盘和设置。研究页左侧约 60% 为事件队列，右侧约 40% 常驻证据；矩阵使用同一候选集合，窄窗口自动调整列数并换行。大窗口持仓使用完整表格，直接展示成本涨跌、强平参考与保证金，无详情侧栏。
- **公共事件与证据**：在交易的 Binance USDT 永续范围内，筛选相对 BTC 强弱、成交活跃和资金费偏离。500 万 USDT 的 24h 成交额门槛，最多 10 个优先标的加 2 个轮转观察；保留来源、单位、时间与缺口。已收盘价格、OI、结算资金费和可见盘口可复核，缺失深度不补成完整数据。
- **按需 AI 查证**：仅在点击后发送公共研究事实，最多两次模型请求，每次输出上限 1,200 tokens，总时限 75 秒；数字、支持/反证、条件引用要经过校验。证据不足时观察，费用与实际用量未知。普通定时行情观察不调用模型；明确启动模拟周期后，自动研究和虚拟汇总复盘共用用户确认的预算。
- **关注、条件提醒与冻结复盘**：关注和提醒分开。最新成交价/资金费阈值每 60 秒检查，连续新鲜样本越界后发送应用内提醒一次。进程退出或休眠不补触发。保存当时判断、失败和弃权；可主动登记 24 小时参考价格观察，保留缺失样本，费用、资金费、滑点和净收益未知。
- **显示与更新**：默认浅色、绿涨红跌，可反转。原生菜单显示币种、标记价与全部持仓带正负号的盈亏数字；只保留一个前置彩色方向图标，对应第一个币种的前次有效报价变化；隐藏金额立即遮罩并取消方向颜色。设置 → 关于与更新支持应用内下载、核对摘要/签名和重启更新。准备完成的更新也会在下次退出时安装。

新研究与凭证入口聚焦 Binance。历史其他交易所适配器保留在源码中，已有配置可删除；它们不属于新版工作台验收范围。真实账户保持只读，无交易所下单或资金转移功能。模拟委托、成交与成本只写入独立本地虚拟账本。

## 下载与使用

[0.2.7 签名版](https://github.com/hash-panda/positionscope/releases/tag/v0.2.7) 修复首次提醒复盘入口，并保留0.2.6的冻结模拟复盘、周期比较与候选策略前向对照。0.2.4 完成菜单栏纯数字盈亏和设置；0.2.5 完成模拟周期与预算。每次 Release 只展示当版变动。签名/原生更新和网站同步证据见[本轮报告](docs/ops/2026-11-07-paper-release.md)。真实用户 Mac、真实账户与模型质量仍需独立验收。

在自己的 Mac 安装，可使用[本机安装与验证脚本](docs/install-and-verify-mac.md)。它先核对固定版本摘要、签名与 Gatekeeper，再把旧应用移到废纸篓并安装；不会读取或迁移旧预览版凭证，系统权限弹窗需本机处理。

打开菜单栏速览可直接查看无需账户密钥的公共参考行情。进入工作台 → 设置 → Binance 连接，仅保存 Binance 只读凭证；应用不会替你验证交易所 Key 的全部权限。关闭交易与提现权限。

在设置中保存模型提供商、Key 与明确模型 ID，再从研究事件右侧点击“AI 查证”。公共研究不会发送持仓或权益。独立的“AI 持仓分析”会发送计算后的逐仓风险事实、平台权益和公共背景，仍属敏感财务信息。持仓分析由用户主动发起；模拟页确认预算后才开启自动公开研究与虚拟汇总复盘，重启/配置变更后需主动恢复。模型费用是真实费用，虚拟本金不能抵扣；不会静默升级型号。

## 模拟周期与复盘

选择 1,000、10,000 或自定义虚拟 USDT 本金，明确确认模型调用硬预算。按公开条件生成模拟委托，等决策之后的新鲜盘口，按数量步进和可见深度检查，再记录模拟成交、每边手续费/滑点假设与已公布资金费。缺口不补零、不补造离线平仓。本地账本不模拟交易所完整保证金与强平机制，成本是假设而非真实账户费率。

暂停仅停止新开仓；结束或新建周期后，旧持仓等待有效后续报价与资金费结算。旧周期、历史订单、盈亏与依据保留，各周期独立展示，不相加不同本金收益率。

定期冻结虚拟汇总，模型只能提出一项有界参数调整，保持风险上限。候选与基准从相同虚拟本金开始，用后续同一研究和行情做对照。至少七天、三十笔成对结算、完整费用且无缺口、净值优势和采样回撤通过预先声明门槛，才影响新决策。三笔样本仅允许提出候选；这些门槛不证明统计显著性或实际盈利。详情见[复盘说明](docs/ops/2026-11-07-paper-review.md)。

## 数据、判断与隐私

名义价值为每笔 `abs(基础币数量) × 本平台标记价`；同币种多空的总名义价值用于集中度，不能把对冲当作分散。参考强平价为空或零时保持未知，强平距离远不能单独证明适合一直持有。5% 不利压力与保留/缩减敞口情景是机械假设，未计费用、资金费、滑点与路径强平，不是收益预测。

事件筛选是横截面线索，成交额活跃不等于相对自身历史放量，OI 增加不等于净资金流入，币种代码不等于已核实项目身份。参考价格观察是无杠杆价格毛变化，不是可执行交易、账户绩效或净收益。无足够历史与成本，不生成胜率、夏普或盈利结论；结构化输出和事实引用不能证明模型语言判断正确。

应用身份为 `app.funagent.positionscope`，使用独立 PositionScope 数据目录，不兼容或迁移旧预览版。账户/模型 Key 等配置通过 Electron 45 异步 `safeStorage` 使用系统钥匙串管理的密钥加密；不可用时保留原文件，不回退明文。公共研究账本为本机 `0600` 权限 JSON，原子保存，**不是加密文件**；也会体现用户关注/提醒偏好，不应公开。模拟事件账本同样为原子保存的本地0600权限JSON，未加密，保留虚拟本金、订单、费用、调用预算与复盘。128MiB上限触发后停止写入并保留历史，长期容量仍未验收。删除所有数据会清理配置、研究与模拟记录、通知两个窗口并拒绝旧响应回填。详见 [secure-storage.md](docs/secure-storage.md)。

真实 Mac 窗口/菜单栏/自动启动、签名包钥匙串权限弹窗、真实账户与模型语义仍需独立验收。签名通过不能证明盈利能力或全部使用场景通过。
