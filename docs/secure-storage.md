# 全新加密配置

按维护者要求不兼容此前预览版：独立应用标识app.funagent.positionscope、PositionScope名称和数据目录；删除旧目录探测、旧单交易所凭据接口与明文迁移代码。不会读取、导入或改写此前应用目录。需要重新配置只读账户。

运行时固定Electron45，使用异步safeStorage API。完整配置加密到settings.vault.json，macOS系统钥匙串管理密钥；本产品仅发布macOS版，不启用未经验证的平台fallback。无明文配置写入、无自制固定密钥。异步写入串行执行；先加密、解密核对，再写0600临时文件、fsync和原子重命名，成功后才发布内存快照。钥匙串不可用、损坏密文、未知格式或临时不可用均不加载账户，也不覆盖原文件。密钥轮换要求先完成验证后的重加密。

“恢复默认”保留交易所/AI凭据；定向移除不影响其他所；“删除所有数据”经确认删除本应用加密文件，失败时保留已提交状态。恢复页面提供解锁系统钥匙串后重启入口。加密文件依赖本机系统密钥，不能直接跨机器复制解密；应用不提供明文导出、不删除共享钥匙串密钥，也不承诺清除系统备份或磁盘快照。运行中的解密值仍在进程内存。

代理URL只从主进程配置读取，不再保存在renderer localStorage。已知代理URL、Key片段及原始响应日志已缩减，不等于全仓库日志审计。

单元测试使用合成凭据与异步AES测试替身，覆盖磁盘无明文、回读、失败保留、并发写入、损坏/未知格式、临时密钥故障、轮换与删除语义。macOS CI另用真实Electron45异步safeStorage在隔离profile两次启动验证系统加密、跨进程读取、重置、定向移除和删除；公开证据不含Key。它不能替代真实签名安装包的钥匙串权限弹窗和用户Mac原生UI验收。没有真实账户或模型调用。

官方依据：Electron45发布（2026-10-21）https://www.electronjs.org/blog/electron-45-0 ，异步系统加密接口 https://www.electronjs.org/docs/latest/api/safe-storage 。按当前稳定版和安装类型定义实现，不使用已弃用同步API。签名发布与验收结论以PR/Actions/Release实际结果为准。
