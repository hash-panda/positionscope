# 模型合成评测基线

这是一组固定合成输入、人工期望数字和人工评审要点，不是模型评测结果。它补充既有单元回归，作为跨模型比较时可追溯的共同案例。当前所有模型的语义质量、失败率、延迟、token和成本均未测。

执行 `pnpm build:main` 后运行：

```sh
node scripts/export-synthetic-eval.cjs > test-results/model-eval-pack.json
```

首次运行前可先创建 `test-results` 目录。工具只读仓库固定的 `tests/fixtures/model-eval-cases.json`，不接收用户持仓路径，不读配置/环境凭证，不加载模型Provider，不发HTTP。输出包含fixture指纹、risk-facts-v2事实和逐例评审标准；不包含模型回答。它不是生产完整提示词或市场研究输入，不能将其结果外推成完整产品质量。

六例：集中且强平价较远、跨所同币对冲、混合资产净空、权益与强平价未知、零权益、账户来源不完整。前五例可分析；最后一例应在模型调用前阻止分析，不能计入模型回答成功或失败率。缺费用/资金费/市场历史等的比较尚未包含，不宣称覆盖所有场景。

固定期望值来自简单算式，例如跨所+1/-1、标记价100，总名义200、净敞口0；各仓分别不利5%损失10，同幅共同冲击价格盈亏0；两者不是同一假设。净空100在共同上涨20%时价格盈亏−20，假设保留50%为−10；这是条件情景，不是已执行操作。黄金值改变或数据无效必须使导出失败。

真实调用只能在明确测试提供商、精确模型ID、允许范围和预算后执行，本工具没有自动调用功能。使用同一份fixture指纹、同一生产提示词版本与调用参数，记录计算器源码提交（git rev-parse HEAD），分别记录提供商/模型/API版本、UTC时间、状态、原始回答（仅合成数据）、token/账单费用及耗时。结构格式检查可复用validateNarrative，但格式通过不能算事实通过；不得将人工标准发送给模型后把其复述当作盲测结果。

每个可分析案例由人工按以下项目记“通过/失败/未验证”，保留引用句和理由，不编综合分：

- 数字/单位/方向与事实一致，可复算；不得捏造强平价、胜率、夏普、VaR或收益。
- 明确共同冲击与各仓分别不利、汇总权益与单所风险的区别；不以对冲证明安全。
- 区分事实、条件和待验证判断；低强平价不直接推出长期持有更好。
- 能说明与本例相关的复核条件，不重复堆叠无关免责声明，不给下单或转账指令。

每家模型报告有效回答数/尝试数、格式失败与人工事实失败数、缺失指标、延迟和真实账单口径；零调用时全部未知。没有人工复核、真实响应与账单的条目保持未验证。Mac原生、真实只读接口和全仓日志验收仍是独立事项，见Issue #3。

## 结构化响应失败与恢复

2026-11-01核对[DeepSeek JSON说明](https://api-docs.deepseek.com/guides/json_mode/)：不能识别为JSON的内容可能替换为空格，即使finish_reason为stop也可能只有空白；该说明没有本次可确认的更新发布日期。

tests/structured-recovery.test.cjs通过真实DeepSeekProvider、AIService和缓存路径的mock adapter，验证四类失败：全空白、空/null内容、截断JSON、合法JSON但分析字段类型错误。HTTP成功或stop都不等于分析成功；当前空内容可能在Provider被解析为默认空对象，但服务的结构校验仍须拒绝。

每类都应在首次调用报错而不自动重试；同一快照下一次显式分析可成功，随后成功缓存可复用。合成Key/错误内容标记不得进入诊断或抛出错误文本。测试不是对提供商实时可用性、收费或语义质量的实测；没有增加自动付费重试，也未改变发布版逻辑。未来真实评测须将这些失败类型和成功后恢复情况单独记录，不能仅看HTTP状态或JSON解析结果。
