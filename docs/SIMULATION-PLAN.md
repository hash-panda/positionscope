# AI 策略模拟工作台：已批准实施计划

2026-11-07 维护者确认实施；菜单栏金额只显示带正负号数字，不显示“浮盈”或单位。当前发布基线0.2.3；以下阶段为计划，不表示已经实现。

## 顺序与验收

1. 0.2.4：一个原生彩色方向图标、币种标记价、全部持仓未实现盈亏的有符号金额；方向与金额口径放tooltip/设置，隐藏金额立即生效；设置右侧整页滚动、清理旧名称；Release仅匹配当前版本章节。类型/逻辑/UI/axe、签名原生更新演练、公证/装订/Gatekeeper通过才发布。
2. 0.2.5：独立模拟账本和周期，1000/10000/自定义USDT；用户在应用中明确启动后才定时调用所选模型。Binance公共行情、严格验证计划、确定性风控/撮合/成本/退出、运行恢复和历史交易；默认总名义敞口不超过权益。新周期保留旧订单、成交、净值和决策；有效报价不足则待结算，不伪造平仓；不自动连接用户真实账户测试。
3. 0.2.6：冻结周期复盘和策略版本、候选策略使用后续行情并行评价、预先声明的晋级门槛、跨周期比较和完整官网合成演示。费用、样本不足、拒绝/未成交/弃权、休眠断档均可见。没有真实模型/市场执行证据则明确标未知，不宣传盈利。

## 固定边界

- 只做本地模拟下单，不存在向交易所发真实订单的适配器、交易权限或资金转移。真实账户只读部分与模拟账本分开，研究模型不接收真实持仓或Key。
- 决策必须在行情之前冻结，后续有效报价才能模拟成交；买卖价差、可见深度、费用假设、资金费和源时间可追溯。不得用未来数据选择过去入场点。
- 可复算账本负责资金、费用与收益，模型不能写收益结果或放宽硬风控。使用十进制定点金额；重复事件、进程重启不得重复结算。
- 每个周期独立本金；旧周期不可被新策略重写，不直接相加收益率。停止开仓不停止有效行情下的退出检查；退出/休眠/断网不补造成交。
- 自动调用仅在用户启动的模拟周期内，设硬调用/token预算、并发和超时；使用明确模型ID。真实模型费用与虚拟交易成本分开，不猜成本。
- 模拟历史包含用户策略偏好，保存在本机受限文件，不公开；损坏读取保留原文件并阻止运行。所有破坏性历史删除与“开启新周期”分开。
- 所有阶段独立PR，CI通过再合并；发布数字版本，使用既有签名链路，不重配已工作的Apple凭证。官网只宣传实际已发布能力，演示固定为合成数据。
