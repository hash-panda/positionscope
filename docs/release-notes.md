# 0.2.1（2026-11-07）

把菜单栏速览与研究工作台分开。480×600 速览显示 Binance 持仓、未实现盈亏及 BTC/ETH 等自选合约的公开 24h 行情；独立工作台默认 1180×760、可调整尺寸，研究页左侧约 60% 为事件列表，右侧约 40% 常驻当前证据。列表与矩阵使用同一候选集合，提供关注筛选、来源、时间、缺口、条件和反证；另有持仓、复盘与设置入口。

- **公开研究**：只覆盖 Binance 在交易的 USDT 永续，按相对 BTC 强弱、成交活跃与资金费偏离筛选。500 万 USDT 24h 成交额门槛，最多 10 个优先标的加 2 个轮转观察；读取已收盘小时价格、未平仓量、已结算资金费与普通可见盘口。盘口覆盖不完整时显示下界，不能补成完整深度；这些是横截面线索，不是历史异常证明或买卖建议。
- **按需 AI 查证**：用户点击后最多两次模型调用，每次输出上限 1,200 tokens，总时限 75 秒；只发送已校验公共市场事实。支持/反证、触发/失效条件与数字引用必须通过校验，证据不足保留观察，模型费用和实际用量未知。不会在定时扫描中自动调用模型。
- **关注、提醒与复盘**：关注与提醒分开。价格或资金费条件在应用运行且联网时每 60 秒观察，首次读数建立基线，连续新鲜样本跨过阈值后触发应用内提醒；不承诺休眠或退出期间通知。冻结当时判断及失败/弃权记录，后续追加观察。可主动登记 24 小时参考价格观察；费用、资金费、滑点与净收益未知，不生成胜率或盈利结论。
- **菜单栏与偏好**：原生菜单文字精简为币种和未实现盈亏，彩色状态图示反映盈亏；默认绿涨红跌，可切换红涨绿跌。隐藏金额时立即遮蔽原生菜单并移除盈亏颜色线索。公开 24h 参考行情位于速览内，不把相对开仓价的变化当作市场涨跌。新安装默认浅色，保留主题和自选配置。
- **检查更新**：设置中的“关于”可主动查询本仓库官方稳定版。只接受纯数字版本及完整发布资产元数据，打开官方发布页后由用户决定下载；不自动下载、替换应用或绕过 Gatekeeper。

公共研究账本是本地 `0600` 权限 JSON 文件，采用原子保存；它不是加密凭证库。账户/模型 Key 等配置继续使用独立应用身份与 macOS `safeStorage` 加密，不回退明文，不迁移旧预览版。删除全部数据会清理研究记录及配置，并使两个窗口和迟到请求失效。

本条记录本版本实现范围。PR、合成测试、UI/axe、实际签名与下载同步证据见 [0.2.1 验收报告](https://github.com/hash-panda/positionscope/blob/main/docs/ops/2026-11-07-numeric-release.md)。签名发布必须通过既有双架构签名、公证、装订和 Gatekeeper 流程；官网与安装器在七项资产核对后同步。真实 Mac 菜单栏与窗口、签名包钥匙串权限弹窗、真实账户、模型语义及收益能力均未验收。
