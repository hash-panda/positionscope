# 本机安装请求与控制边界

2026-10-25，维护者要求卸载自己Mac上的旧版、安装新版并验证。当前会话执行环境为Linux；可用工具和插件检索没有提供可连接该Mac的本机文件系统、终端或原生应用控制入口。因此未执行用户Mac的卸载/安装/启动，未读取旧凭据、真实持仓或钥匙串。

为缩小配合范围，提供 scripts/install-verified-mac.sh，固定beta.5公开ZIP摘要，使用系统工具验证版本/Bundle ID/codesign/Gatekeeper后，按已知Bundle ID识别应用并移入废纸篓、安装新版与观察主进程。未提交前失败尝试恢复旧应用；不清除旧配置，不禁用安全校验，不自动上传报告。用户在Mac终端运行；本地管理员密码和系统弹窗由用户在本机处理。详细范围及未覆盖场景见 docs/install-and-verify-mac.md（仓库根目录相对路径）。

本地两项新增Node检查通过：固定摘要对应实际公开记录、语法正确、非Mac及未知参数在安装前退出。Mac CI新增 --verify-only 验证真实公开包，结果以PR检查为准。该模式不卸载、安装或启动，不能验证事务回退、受保护应用移动、真实弹窗或用户Mac原生UI。现有已验证版本不重建、不覆盖。

仅有进程启动也不视为原生体验验收；报告固定标注Keychain/native interactions未验证、真实账户未测试。真实账户接入需维护者自己配置只读凭证，私有信息留在本机。
