# 官网与设置组件统一

维护者要求统一官网/应用标识和色板、替换原生下拉并评审其他输入。采用assets/brand/tokens.css共用深墨/暖金/涨跌语义色；官网生成器复制并验证一致，所有内页与首页用应用主图、favicon和触屏图标。保留应用浅色主题对应的语义色。

Reka UI固定2.11.0；AppSelect、Switch、Slider统一组件样式，AppTextInput保留文本输入语义与输入法，SecretInput覆盖凭证和代理显隐，代理默认遮蔽。不把浏览器标准input元素的存在视为视觉未组件化。

回归发现并修复：在集成基线的取消回归中，Reka自动推导的选中标签会随弹层卸载短暂清空；现在由受控选项直接渲染标签，保证关闭后仍显示当前值。下拉Escape会触发全局设置页退出；弹层aria-hidden背景仍含可聚焦节点。现在组件优先处理Escape，背景inert并在关闭/卸载时恢复；保存禁用后恢复焦点也通过人工控制的异步fixture验证。320px弹层边界、键盘取消、数字设置类型、滑块键盘提交、浅色模式、凭证校验和保存失败均通过UI/axe，无浏览器错误。46项Node、5项Python、类型、生产构建及官网源码检查已通过；本轮未执行用户Mac验收。

该分支已叠加#25的OKX数量/方向、Bybit签名与风险事实修正；合并仍需#25先落地并在新默认分支基线上通过CI。版本预留beta.8；下载和实际发布以Release证据为准，不覆盖旧版本。官方组件资料：https://reka-ui.com/docs/components/select 。
