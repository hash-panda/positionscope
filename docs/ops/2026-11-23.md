本轮复用 [#93](https://github.com/hash-panda/positionscope/issues/93)，为隔离部分成交实验增加显式启用的市场单最低名义金额模式。输入标记价证据包含 symbol、price、observedAt、fetchedAt 与 premiumIndex 来源。缺失、格式无效、错标的、错来源、过期或未来采集证据保持 admission=unverified，等待下一有效盘口；金额不足时记录 rejected。通过时冻结原单数量、最低金额、价格来源与时间，后续原单部分成交继续复用已准入记录。

固定回归先复现：盘口 99/100、标记价 4、原单数量 1、最低名义金额 5，旧实验仍成交。启用新模式后拒绝该单；标记价 5 正好通过，4.999999999999 拒绝，使用十进制定点原始乘积比较。另测无证据、错标的、零/无效价格、错来源、未来/过期时间、补证据恢复、部分成交和 JSON 重放。本地 241 Node、25 Python、类型、构建及七页官网源码检查通过。

该模式只用于合成实验，原有实验入口默认保留 unchecked，应用模拟账户尚未接入。15 秒时效和 2 秒源时钟容差沿用已有盘口实验约定，是本地实验参数。实际市场单生命周期、reduce-only 例外、全部交易所过滤器、合约规则变化、资金费、部分平仓、风险预算和磁盘崩溃恢复仍待验收。
