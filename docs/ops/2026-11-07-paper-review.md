# 2026-11-07：模拟复盘与前向对照

范围：在已合并的 #75/#77 模拟账本上增加周期比较、每日/归档冻结汇总及受限候选策略。纯本地模拟，无真实订单接口；真实账户、真实模型质量和盈利能力均未验证。

- 运行满 24 小时汇总；归档周期生成最终本地汇总。至少三笔已平仓且资金费完整时才允许模型提议，不代表统计样本充分。复盘共用用户已确认的滚动调用预算，预留持久化后才调用，失败不退还额度。
- 模型只接收虚拟周期汇总、冻结策略、对照门槛；不发送真实持仓、凭证或自由输入。输出严格枚举与已知事实引用，必须保留反证；不允许生成代码、提高风险预算、修改历史。
- 候选一次只调一个有界参数，保持原策略运行；两个等本金空账户接收后续同一假设与盘口，各自执行相同确定性撮合和成本规则。旧交易不回放，不按历史结果选优。
- 前向门槛预先固定为至少七天、三十笔成对平仓、全部费用核对且无观察缺口、候选净值领先本金至少 0.5%、采样回撤不高于基准且不超过 5%。这是产品筛选规则，不是显著性检验或盈利证明。样本不足则保留原策略；暂停/结束周期会终止对照。采用只影响以后决策。
- 复盘页按周期显示本金、已平仓暂计净盈亏、手续费、资金费和冻结依据。不同本金收益率不直接相加；未知值不补零。金额隐藏同步覆盖复盘。

验证（本地实际执行）：221 项 Node 测试、Vue 类型检查、主进程与 renderer 构建通过。新增校验覆盖时间/样本/费用/缺口/回撤门槛、候选风险边界、旧交易冻结、未来事件对照及模型调用先预留。UI/axe、Mac 原生检查在 PR CI 中运行，以最终链接为准，未运行的不写通过。

限制：仅应用运行联网时观察，休眠/退出不补成交；可见盘口不模拟真实排队。阈值为预先声明工程规则，未验证经济优势；长期容量和真实模型费用未知。沿用 Binance 官方只读市场接口：https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data （2026-11-07 核对）。
