## 官方资料核对（截至 2026-11-08）

- **Binance USDⓈ-M 用户流**：官方仍提供 listen key 用户流；保活请求权重为 1。仓位流比 REST 轮询更及时，但引入 listen key 生命周期、24 小时连接重建、乱序/断档处理和真实账户对照。本次不为追新替换已稳定 REST。最小验证：在明确授权的只读测试账户中让 REST 与 WebSocket 并行，比较交易所事件时间，覆盖保活、24 小时重连、断档与乱序；数量变化不能推断成交或转账。[官方文档](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/ws-api/user-data-streams)
- **Bybit**：官方仓位 WebSocket 明确说明创建、修改或取消订单时，即使仓位没有实际变化也会发消息。这再次支持当前“事件/仓位变化不等于成交或资金流”的口径；当前版本只支持 Binance，不新增适配。[官方文档](https://bybit-exchange.github.io/docs/v5/websocket/private/position)
- **OKX**：当前产品范围已收敛到 Binance；没有发现应迫使本轮恢复 OKX 的变化，不扩范围。
- **DeepSeek**：2026-10-17 官方新增 Search/Fetch，并更新 `deepseek-flash` alias；Responses API 支持 `json_schema`，但服务端搜索只适用于特定模型且产生额外工具调用/费用。本轮不接入，避免把外部搜索成本、来源治理和模型生命周期带入已稳定的公开事实管线。最小验证：合成 schema 失败关闭、逐来源字段、每周期明确预算、绝不发送账户数据，再以获准真实模型对比费用和可复核性。[更新日志](https://api-docs.deepseek.com/updates/) · [Responses API](https://api-docs.deepseek.com/api/create-response/)
- **同类菜单栏/组合工具与其他模型 SDK**：未发现足以推翻当前“菜单速览 + 独立研究工作台 + 明确模型 ID”的实质变化，不为凑热点改造。
