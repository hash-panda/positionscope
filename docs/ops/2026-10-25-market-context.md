# 2026-10-25 公共市场背景与研究观察

接续 #23、PR #25。首版范围是Binance在交易的USDT永续合约，不能改称“整个加密市场”。现有四家账户监控保持只读，不安装下单或转账工具。

## 实现与边界

- 按需通过固定host/GET路径白名单读取exchangeInfo、24hr ticker、premiumIndex、fundingInfo/fundingRate、openInterest和1h klines。研究页可无密钥使用；只有点击研究/刷新或AI分析时读取，不跟随5秒账户轮询。
- 市场宽度显示有效行情覆盖数/合格合约数、涨跌平、中位数和USDT成交额。成交活跃前5只按24h成交额排序，不冒称盘口流动性。最近30天上线前5只代表平台合约上线，需另查基本面、估值、代币解锁和需求，不能推导买点或“早期价值”。
- BTC/ETH及最多10个其他标的显示平台参考资金费、下次时间、最近实际结算与间隔；优先已公告fundingIntervalHours，否则仅从3次一致结算间隔观测，不默认8小时、不保证下次。OI以基础币数量展示；每个标的最多200根已收盘连续小时K线，至少25根。窗口涨跌、收盘价最大回撤、小时对数收益样本标准差×sqrt(365×24)为标的价格统计，不是账户收益/胜率/夏普。
- 资金费现金流仅对Binance同合约按当前仓位/标记价与参考费率假定下一次费率不变：-有符号名义价值×参考费率×保留比例。正为收取，负为支付，不年化预测；不把Binance报价用于OKX/Bybit/Hyperliquid资金费，也不改用其价格计算其他平台强平距离。
- 8秒单请求超时、最多3并发、每次45秒新请求预算、最多12标的；60秒复用原时间快照，15分钟元数据缓存；429/418尊重Retry-After并冷却，无自动重试洪峰。上游响应、配置、代理和账户密钥不进入错误文本。时间过期、空数据、断K线、未知交易对保留缺口，不补零或偷偷用旧行情。
- AI上下文含市场范围、源、时间、单位、窗口与缺口；缓存键覆盖公开上下文。分析说明明确会发送逐仓风险事实和平台权益给所选模型，行情接口只收到交易对，没有数量/权益/账户标识。结构校验不能证明模型结论正确。

## 原始来源与取舍

核对日期2026-10-25。没有发现需要凭追新替换当前模型传输或REST的证据；下列能力是当前可核对规范，不虚构今天才发布的更新。

- [Binance USD-M公共市场REST](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data)：直接支持上述原始字段；最小验证为合成时间/单位、历史、缓存、缺口与限流回归。未用真实账户或真实模型请求测试。
- [Binance官方JS connector](https://developers.binance.com/en/docs/sdks-tools/connectors/javascript)：模块化Node SDK有签名/连接管理/类型；未来只有等价口径测试和维护收益明确才替换已修复REST。
- [OKX Agent Trade Kit](https://github.com/okx/agent-trade-kit)、[Bybit trading-mcp](https://github.com/bybit-exchange/trading-mcp)：提供市场/账户及交易工具访问，不是经过验证的盈利模型。候选接入必须显式只读配置和工具允许列表、禁止写操作；本轮不引入MCP依赖或交易能力。
- [CoinGecko keyless官方说明](https://docs.coingecko.com/docs/keyless-public-api)：无密钥端点适合原型，官方明确不适合生产工作负载/计划轮询。全市场市值/主导率/基本面生产接入仍需用户选择具有合适许可与额度的账户方案，不擅自购买或把原型公共入口当生产保障。

## 验证

本地53项Node、5项Python、类型、生产构建与完整UI/axe通过；新增市场fixture覆盖范围/单位、已收盘价格/缺口、缓存、3并发、429冷却、编码输入、资金费方向/平台边界、320px研究页和失败刷新保留原时间。全部为合成响应或mock；没有真实交易所持仓、模型调用或付费调用。最终CI/签名/Release另行核对。

仍未验证：用户Mac、真实API字段和区域网络、真实模型事实一致性、实际读懂/留存效果。#23后续保留跨平台公共市场源、OI历史/盘口深度、长期价格/账户历史、解锁及基本面、经许可全市场数据和研究候选的反例评估。不把本轮价格观察功能称为可盈利早期策略。
