# 应用图标修复

用户反馈安装包仍显示默认Electron图标。源码证据：package.json没有mac.icon，createTray使用nativeImage.createEmpty；网页p.并不等于应用包图标。

本轮设计“取景框＋仓位刻度”，深墨色/暖金色主图、黑色透明Template菜单栏版，新增多尺寸ICNS及18/36px资源；统一首页、关于、官网与favicon。主图通过内置image_gen生成，提示与资产说明在assets/brand/README.md。构建显式指定ICNS，菜单栏资源单独打入Resources/brand；签名前检查CFBundleIconFile、实际ICNS与两张Template文件逐字节一致，结果进入公开verification JSON。安装包版本升为beta.6，不覆盖beta.5。

本地类型、36项Node、5项Python与生产构建通过，包含拒绝Electron/错误图标和Retina菜单栏资源漂移的检查。本地UI/axe回归在恢复字体路径后通过，无浏览器错误；首轮因过期临时字体路径中断，未将中断报告为通过。Mac iconutil/Electron解码、像素/Template/Retina检查结果以本PR CI为准。二进制只按既有双架构签名/公证/装订/Gatekeeper流程发布，未成功前官网仍指向已验证beta.5。

没有访问用户Mac、真实账户或Key；资源/nativeImage检查不等于真实用户菜单栏外观、钥匙串弹窗或金融数据验收。beta.5与beta.6应用身份和加密格式一致，保留同一PositionScope配置目录，不导入更早预览版。
