# 2026-11-07 Binance 合约标识与失败恢复修复

关联 [Issue #52](https://github.com/hash-panda/positionscope/issues/52)。提交基于 master `3905cf27f473b8899d53f51a7fa93aed9be939bd`，保留当日已合并的分页测试及报告。本轮只修复已复现的读取和错误状态问题；新版 AI 工作台仍是独立设计提案。

## 证据与范围

2026-11-07 查阅 Binance [2025-10-09 UTF-8 支持公告](https://www.binance.com/en/support/announcement/detail/7ae395540d4249f5af959e79c7cea64f)及 [2025-10-20 中文 USDT 合约公告](https://www.binance.com/zh-CN/support/announcement/detail/a6aeec228c6a403da616e873011317ea)。旧 ASCII 校验拒绝官方已有汉字合约。在真实适配器及聚合器中注入完全合成的价格、数量、凭证和响应，可以复现持仓返回空数组与 UNKNOWN；账户成功也不能覆盖持仓错误，连续三次失败后不再发起该所读取。没有据此推断维护者实际持仓或确定其本机故障原因。

修复统一 Binance 有界 Han/ASCII 标识校验，贯穿持仓、风险事实、公共行情及 AI 上下文；符号不转写、不 Unicode 归一化，拒绝控制符、空白、路径、其他脚本和不一致资产映射。公开行情仍要求交易所 metadata 匹配 USDT 永续，其他平台支持范围不扩大。本地错误通过可信类型区分持仓、配置、账户与不支持合约，原始消息、任意代码、响应和合成私有标记不进入诊断。

首次失败不再显示 +0.00 或持仓 0；真实成功空仓仍显示零。只有保留快照才显示“含上次数据”。任何操作达到原有暂停阈值时显示暂停；重新连接和底部刷新都明确清除错误后重试，成功快照恢复正常状态。暂停阈值与只读权限不变。

## 实际验证与发布条件

本地类型、102 项 Node、5 项 Python、生产构建、静态官网及差异检查通过。新增 Node 合成回归覆盖完整 adapter → manager → facts → public GET → 假模型链路、UTF-8 query 保真、恶意标识拒绝、诊断隐私和跨操作暂停状态。未连接真实账户或模型。

新增浏览器断言覆盖首次失败的未知值、旧数据标签、暂停提示、重新连接及底部刷新恢复、成功空仓零值。本地浏览器不可用且下载失败，本地 UI/axe 未验证；必须以本 PR 的既有 GitHub CI 为合并门槛，同时要求合成 Mac 系统存储/品牌/安装器检查通过。CI 和签名结果在 PR 及后续发布记录中核对，不将待运行写为通过。
