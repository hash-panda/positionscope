# 本机替换安装与验证

此脚本仅安装已发布的 v0.2.0-beta.5，不构建二进制。使用系统 Bash 3.2，无需 Homebrew、Python 或 Xcode。需要 macOS 13.0+，自动按实际硬件选择 Apple Silicon 或 Intel（包括 Rosetta 终端）。

运行 `bash scripts/install-verified-mac.sh`：下载固定版本 ZIP，核对固定 SHA256，检查 Bundle ID/版本、codesign 与 Gatekeeper；任何一项失败都不替换旧应用。不关闭 Gatekeeper、不删除 quarantine 属性。

脚本只检查 /Applications 与 ~/Applications 中 .app 的 Info.plist，识别本项目的新旧 Bundle ID。先验证并暂存新版，再对匹配的主进程发送 SIGTERM（最多等待10秒，不强杀），将旧应用移到废纸篓 PositionScope-previous 文件夹，然后原子放置新版、再次验签并启动。路径冲突不覆盖。受保护的旧应用移动可能在本机请求 sudo 密码，不要在聊天中提供。提交安装前失败会尝试恢复已移动的旧应用；冲突或恢复失败保留废纸篓副本。启动失败时保留已验证安装与旧副本供排查。不要清空废纸篓，直到本机验收完成。

不读取、迁移或删除 Application Support 中的旧配置，不检查或导出钥匙串、交易所凭证、私有持仓、模型Key。副本位于其他目录或外接盘时不扫描，需在Finder自行移除。识别旧应用只用于卸载，不构成配置兼容。新版重新配置只读账户。

`--verify-only` 仅下载、校验和解包验签，不扫描旧应用、不安装、不启动。CI使用该模式核对真实公开发布包，不能替代用户Mac替换、权限弹窗或原生UI验证。

## 本机报告与验收

脚本输出并在本机临时目录保留0600报告，只有版本、系统版本、架构、签名/Gatekeeper状态、旧应用数量、安装与进程状态；没有用户名、完整应用路径、Key、地址、持仓或金额。报告未自动上传。`launch_process=PASS`只代表启动后观察到主进程，不表示原生交互正确。

仍需在本机核对：

1. 新版菜单栏图标打开480×600窗口，显示正确版本；旧应用不再运行。
2. 设置/关于/空态可打开，窗口失焦行为正确；隐藏金额与键盘操作正常。
3. 保存配置时由用户在本机处理系统钥匙串权限弹窗。重启后设置保留、删除/恢复行为正确；不要为了反馈发送真实凭证。
4. 真实账户是独立验收：用户自己配置只读连接，核对交易所原始数量、方向、标记价与时间；私有数据留在本机。不要求为测试下单或转账。

若当前ChatGPT会话只有云端环境，本脚本需由用户在Mac终端运行。云端代码检查、Mac CI或请求启动不能证明用户电脑已卸载、安装或验收。问题反馈只需报告及脱敏现象；不要上传旧配置文件。
